# 게임 검증

게임 설계가 의도한 플레이를 만드는지 평가한다. 각 영역은 실패 조건, 검증 방법, 측정 항목으로 구성한다. 기록과 판정 절차는 [작업 흐름 > 검증 수단](../workflow.md#검증-수단)을 따른다.

## 적응

참조: [게임 설계 > 플레이 목표](design.md#플레이-목표), [게임 설계 > 적응 입력](design.md#적응-입력), [게임 설계 > 적응 변화](design.md#적응-변화)

### 실패 조건

- 대응 가능한 대안 빌드가 있는 실험에서도 한 빌드가 장기간 사실상 유일한 선택이 된다.
- 지역별로 다른 전투 압력을 주어도 그 차이가 적응 상태에 반영되지 않는다.
- 전투 압력을 바꿔도 적응과 상대적 사냥 효율이 반응하지 않는다.
- 적응이 대응 가능한 속도를 넘어 반복적으로 바뀌거나 오래된 전투 영향이 줄어들지 않는다.
- 저항이나 행동 특성에 약점·비용이 따르지 않거나 모든 저항이 영구적으로 쌓인다.
- 기존 빌드로 사냥할 수 있는 지역과 개체군이 모두 사라진다.
- 소수 고레벨 플레이어의 짧은 사냥이 정한 기여량·변화율 제한을 넘는다.

### 검증 방법

- 수치 모델에 피해의 여섯 분류를 모두 포함한다. 초기에는 분류별 값의 종류를 최소한으로 구성한다.
- 속성만 다른 빌드, 공격 방식만 다른 빌드, 여러 속성을 쓰는 빌드를 비교한다.
- 빌드·지역 유지, 대상 변경, 지역 변경, 최고 효율 지역으로 즉시 이동, 조사 기록 확인 후 지연 대응을 행동 유형으로 둔다.
- 행동 유형별 플레이어를 같은 세계에서 함께 실행하며 구성 비율을 바꾼다.
- 지역 수, 전투 압력의 지역별 차이, 감쇠 속도, 적응 상한, 고레벨 플레이어의 기여량을 바꾼다.
- 피해 분류의 누락과 `해당 없음` 처리, 유효 피해의 중복 합산, 사용률 직접 보너스 여부를 자동 테스트로 확인한다.
- 미정인 입력의 반영 여부는 실험 가정으로 명시한다.

### 측정 항목

- 빌드별 사용률과 사냥 효율
- 지역·개체군별 적응 상태와 변화율
- 적응 변화의 반복 주기와 오래된 영향의 감소량
- 사냥 가능한 지역이 없는 플레이어 비율
- 대응 행동 후 사냥 효율 회복 시간
- 자동 테스트 결과

## 접속과 미접속 보상

참조: [게임 설계 > 접속과 미접속 보상](design.md#접속과-미접속-보상), [게임 설계 > 적응 변화](design.md#적응-변화)

### 실패 조건

- 정한 미접속 보상 누적 시간 안에서도 성장 보상을 얻지 못한다.
- 통상적인 미접속 후 사냥 효율 하락폭이 허용 범위를 넘는다.
- 복귀 후 다른 지역이나 대상을 찾는 시간이 허용 범위를 넘는다.
- 접속 상태 전환이나 누적 시간 상한 처리에서 보상이 누락되거나 중복 지급된다.

### 검증 방법

- 접속·미접속 보상 비율, 최대 누적 시간, 적응 속도를 함께 바꾼다.
- 미접속 기간을 달리하며 보상량과 복귀 후 사냥 효율을 비교한다.
- 복귀 후 대체 사냥터를 찾는 과제를 플레이 테스트로 확인한다.
- 상태 전환 시 보상 누락·중복, 효율 차이, 누적 시간 상한을 자동 테스트로 확인한다.

### 측정 항목

- 접속 상태별 단위 시간당 보상량
- 미접속 기간별 누적 보상량
- 복귀 후 사냥 효율 하락폭
- 대체 사냥터 탐색 시간
- 자동 테스트 결과

## 경제

참조: [게임 설계 > 장비와 성장](design.md#장비와-성장), [게임 설계 > 경제와 거래소](design.md#경제와-거래소)

### 실패 조건

- 이전 성장 구간의 재료가 반복 소비되지 않고 계속 누적된다.
- 공급 부족 시 고레벨 플레이어의 직접 사냥이 대체 공급 경로가 되지 못한다.
- 해당 성장 구간의 플레이어에게 재료를 구매할 경제적 유인이 없거나 재료 판매가 성장에 도움이 되지 않는다.
- 특정 권역의 인구가 적으면 성장이 사실상 멈춘다.
- 공동 프로젝트가 과잉 재료를 처리할 사실상 유일한 선택이 된다.

### 검증 방법

- 신규 플레이어가 많은 상태, 적은 상태, 없는 상태를 비교한다.
- 특정 권역의 인구가 적은 상태와 고레벨 플레이어의 비율이 높은 상태를 비교한다.
- 재료 가격을 바꾸며 직접 사냥과 거래의 성장 효율을 비교한다.
- 공동 프로젝트를 도입할 경우 참여 여부에 따른 재료 소비와 성장 효율을 비교한다.

### 측정 항목

- 재료별 생산량·소비량·재고량·가격
- 직접 사냥과 거래의 성장 효율
- 성장 구간별 재료 판매 수익
- 권역별 성장 속도
- 공동 프로젝트 참여 여부에 따른 재료 소비량과 성장 효율

## 거래소

참조: [게임 설계 > 경제와 거래소](design.md#경제와-거래소)

### 실패 조건

- 악용 탐지율이나 차단율이 정한 기준에 미달한다.
- 정상 거래의 오탐률이나 보류 시간이 허용 범위를 넘는다.
- 판매자 선택 금지나 가격 우선 체결 규칙을 위반한다.
- 거래 전후의 자산 증감이 체결 내역과 일치하지 않는다.

### 검증 방법

- 매물이 없는 품목을 고가에 등록한 뒤 다른 계정으로 구매한다.
- 거래량이 적은 품목을 반복해서 왕복 거래한다.
- 여러 부계정에서 본계정으로 자산을 모은다.
- 정상적인 희귀 아이템의 첫 고가 거래를 함께 평가한다.
- 악용 대응의 성능과 정상 거래의 영향을 비교해 대응 방식을 결정한다.
- 판매자 선택 불가, 가격 우선 체결, 자산 증감의 정합성을 자동 테스트로 확인한다.

### 측정 항목

- 악용 탐지율과 차단율
- 정상 거래 오탐률과 보류 시간
- 체결 전후 자산 증감
- 자동 테스트 결과

## 플레이 경험

참조: [게임 설계 > 플레이 목표](design.md#플레이-목표), [게임 설계 > 세계와 사냥터](design.md#세계와-사냥터), [게임 설계 > 적응 정보와 튜토리얼](design.md#적응-정보와-튜토리얼), [게임 설계 > 포획과 도감](design.md#포획과-도감), [게임 설계 > 경쟁과 최종 성장 이후](design.md#경쟁과-최종-성장-이후)

### 실패 조건

- 적응을 이해해야만 기본 성장을 진행할 수 있다.
- 외형과 전투 반응으로 변화를 알아차리거나 일반 지역의 차이를 이해하기 어렵다.
- 적응이 단순한 하향 조정으로 느껴지거나 기존 빌드를 버리는 것만이 대응으로 인식된다.
- 다음 사냥 목표를 찾기 어렵거나 기다림 외의 선택을 반복해서 찾지 못한다.
- 도감 보상이 사실상 모든 변종의 수집을 강제한다.

### 검증 방법

- 수치 모델에서 수용 가능한 조건을 찾은 뒤 전투·외형·조사 기록·성장·사냥터 이동을 연결한다.
- 플레이어에게 변화 인지, 대응 선택, 다음 사냥 목표 탐색 과제를 수행하게 한다.
- 보호구역을 거친 뒤 일반 지역의 적응을 이해하고 대응하는 과정을 관찰한다.
- 도감·시즌·최종 성장 이후 목표는 해당 기능 도입 시 참여 동기와 성장 격차를 평가한다.

### 측정 항목

- 변화 인지·대응 선택·다음 목표 발견에 걸린 시간
- 플레이어의 선택과 선택 이유
- 적응과 일반 지역의 차이에 대한 이해
- 도감·시즌·최종 성장 이후 목표의 참여 동기
- 보상에 따른 성장 격차
