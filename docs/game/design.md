# 게임 설계

게임 목표와 규칙의 기준이다. 미정인 정책·수치·방식은 [미결정 사항](open-questions.md), 설계를 평가할 조건은 [게임 검증](validation.md)에서 관리한다.

## 플레이 목표

- 자동 사냥, 장기 성장, 장비와 스킬 구성, 거래가 기본 플레이를 이룬다.
- 시간과 자원을 더 많이 투자한 플레이어가 더 강해지는 것을 정상적인 결과로 본다.
- 적응은 장기간 고착되는 빌드를 흔들고 지역별 차이를 만드는 장치다. 기본 성장 구조를 대체하지 않으며, 깊게 이해하지 않아도 진행할 수 있어야 한다.
- 사용률이 낮다는 이유만으로 빌드에 직접 보너스를 주지 않는다. 상대적 이점은 지역의 적응 상태에서 생긴다.

## 닉네임과 개인 색상

- 플레이어는 닉네임을 사용하며, 채팅에서 닉네임과 개인 색상을 함께 표시한다.
- 최초 가입 과정에서 개인 색상을 무작위로 뽑고 확정한다. 확정 전에는 제한된 횟수 안에서 다시 뽑을 수 있다.
- 한 계정이 소유하는 개인 색상은 하나다. 같은 색상 코드를 여러 계정이 동시에 소유할 수 없다.
- 서로 비슷한 색상은 허용한다. 유사한 색을 찾거나 다른 플레이어와 색을 맞추는 경험을 제한하지 않는다.
- 개인 색상을 닉네임과 명찰의 표현에 사용한다. 색상에 관계없이 닉네임과 채팅 내용을 읽을 수 있어야 한다.

## 세계와 사냥터

| 용어 | 의미 |
| --- | --- |
| 권역 | 하늘·땅·바다로 나뉘는 세계의 큰 구분 |
| 지역 | 권역 안에서 사냥 대상을 선택하고 적응 상태를 관찰하는 장소 |
| 개체군 | 한 지역에서 적응 상태를 공유하는 개체 집단 |
| 종 | 개체의 기본 생물 분류 |
| 변종 | 같은 종 안에서 적응으로 특성이 달라진 형태 |
| 빌드 | 장비와 스킬의 조합 |

- 무한한 숫자 스테이지를 순서대로 진행하는 방식을 기본 구조로 삼지 않는다. 여러 사냥터와 개체군 중 목적에 맞는 곳을 고른다.
- 지역 해금, 보스, 탐험 목표 등 이정표로 장기 진행 상태를 보여준다.
- 기다림은 정상적인 해결책이지만, 기다리는 것만 가능한 상태를 반복해서 만들지 않는다.
- 플레이어는 방치를 이어가거나, 대상·지역·장비·스킬을 바꾸거나, 재료를 거래하거나, 다음 성장 순서를 바꿀 수 있다.

## 접속과 미접속 보상

- 접속 중 자동 사냥과 미접속 보상에는 서로 다른 효율을 적용한다. 접속 유지에 더 높은 효율이나 추가 보상을 제공할 수 있다.
- 미접속 중에도 최대 누적 시간까지 성장 보상을 얻는다.
- 통상적인 한 번의 미접속 기간만으로 기존 사냥 설정이 사실상 무효가 되어서는 안 된다. 통상 기간과 허용할 효율 하락폭은 별도로 정한다.
- 접속 후에는 사냥터·장비·스킬·거래를 다시 선택할 수 있다.

## 장비와 성장

- 고정 직업은 두지 않는다. 현재 장비와 스킬 구성이 역할을 만든다.
- 현재 구성의 특성을 요약한 이름이나 태그를 표시할 수 있다.
- 모든 스킬은 장기적으로 마스터할 수 있다. 초중반의 선택은 성장 순서에 대한 우선순위다.
- 이미 성장시킨 장비나 스킬로 교체하는 행위 자체에 반복 비용을 붙이지 않는다.
- 상위 장비의 제작과 강화에도 이전 성장 구간의 재료를 사용한다.
- 고레벨 플레이어도 이전 성장 구간의 사냥터에서 재료를 직접 얻을 수 있다. 신규 플레이어가 없어도 공급 경로는 유지된다.
- 고레벨 플레이어에게는 현재 사냥터의 수익을 포기하는 비용이 생긴다. 보통은 해당 성장 구간의 플레이어에게 구매하고, 가격이 충분히 오르면 직접 사냥할 유인이 생기도록 설계한다.

## 적응 입력

- 적응 단위는 `지역 × 개체군`이다. 같은 종이라도 지역이 다르면 다른 상태를 가질 수 있다.
- 적응의 기본 입력은 실제 전투에서 감소시킨 체력인 유효 피해다. 공격 횟수·막타 여부·오버킬 피해를 직접 입력으로 사용하지 않는다.
- 실패하거나 철수한 전투의 기록을 포함할지는 미정이다.
- 적응 방향은 노출된 공격의 성질, 적응 강도는 개체군이 받은 사냥 압력의 크기를 나타낸다. 두 값은 분리해 계산한다.

유효 피해를 일으키는 모든 전투 효과에는 아래 여섯 분류를 기록한다. 해당하지 않는 분류에는 `해당 없음`을 기록해 누락과 구별한다. 실제 분류값은 전투·스킬 정의에서 가져온다.

| 분류 | 기록할 내용 |
| --- | --- |
| 피해 속성 | 속성과 복합 속성별 실제 피해량 |
| 피해 발생 주체 | 플레이어·소환체·설치물 등 피해의 출처 |
| 전달 방식 | 접촉·투사체 등 피해 전달 방식 |
| 거리와 위치 | 피해 발생 시 공격자와 대상의 거리·위치 관계 |
| 대상 범위 | 대상 수와 광역 효과 여부 |
| 피해 발생 시점과 지속 방식 | 즉시·지속 피해의 구분과 시간 분포 |

- 새로운 속성이나 공격 방식은 분류에 반영한다. 분류가 누락된 피해를 적응 계산에 정상 기록처럼 포함하지 않는다.
- 분류별 노출량은 각각 집계하되, 강도 계산에 쓰는 전체 유효 피해는 한 번만 합산한다.
- 스킬 이름이나 빌드 이름 자체를 적응 방향으로 삼지 않는다.
- 상태이상·방어 감소·방어·회복·이동 등 직접 피해를 주지 않는 효과와 행동은 해당 기능이 있을 때 기록한다. 적응 반영 여부와 방식은 미정이다.

## 적응 변화

- 적응으로 저항이나 행동 특성이 생기면 다른 약점이나 비용이 따른다.
- 한 개체군이 모든 저항을 영구적으로 쌓을 수 없다. 새 적응이 커지면 기존 적응이 약해지거나 다른 능력에서 비용이 발생해야 한다.
- 적응이 진행돼도 기존 빌드로 사냥할 수 있는 지역이나 개체군이 모두 사라져서는 안 된다.
- 전투의 영향은 계속 누적되고 오래된 영향은 서서히 줄어든다. 공개된 주간 초기화 시각이나 고정된 메타 교체 시각을 두지 않는다.
- 플레이어가 변화를 알아차리고 대응할 수 있는 속도보다 세계가 더 빨리 변해서는 안 된다.
- 고레벨 플레이어의 실제 사냥도 적응에 영향을 준다. 한 명의 짧은 사냥이 지역을 급변시키지 않도록 기여량과 변화 속도를 제한한다.

## 적응 정보와 튜토리얼

- 적응은 외형, 전투 반응, 조사 기록을 차례로 살펴보며 이해할 수 있어야 한다.
- 털·갑각·체형·피부·자세·이동 방식·개체 간 거리 등으로 변화 방향을 드러낸다.
- 외형은 적응이 강해지거나 약해져 정해진 단계 전환 조건을 충족할 때 바뀐다. 적응량이 조금 변할 때마다 외형을 연속적으로 바꾸지 않는다.
- 외형은 현재 적응 상태를 나타낸다. 약해진 적응의 외형이 남아 현재 저항과 약점을 오해하게 해서는 안 된다.
- 전투에서는 피해 숫자·아이콘·피격 효과·타격음·경직·이동 행동 등 둘 이상의 신호를 함께 사용한다.
- 조사단은 NPC 조직이다. 조사단 기록은 이미 일어난 변화를 설명한다. 정확한 내부 계수나 다음 변화 시각은 공개하지 않는다.
- 개발자가 규칙 자체를 바꾼 경우에는 조사단 기록과 별도의 운영 공지로 알린다.
- 극초반은 적응이 일어나지 않는 보호구역으로 둔다. 기본 전투와 고정된 상성을 먼저 배우고 일반 지역에서 적응을 경험한다.
- 보호구역은 핵심 거래 재료의 주요 공급처가 되어서는 안 된다.

## 포획과 도감

- 변종의 포획은 직접 접속한 상태에서 시도한다. 성공한 개체는 도감에 기록한다.
- 도감은 같은 종의 지역별 변화와 과거 상태를 남긴다.
- 도감 완성에 대한 능력치 보상은 선택 사항이다. 도입 시 작은 영구 능력치로 제한하고, 모든 변종 수집을 사실상 강제하지 않는다.

## 경제와 거래소

- 화폐는 거래소 수수료·강화·제작·정제 등 반복되는 비용으로 회수한다.
- 재료에는 반복 소비처가 있어야 한다. 상위 장비 강화·정제·합성·소모품·공동 프로젝트를 사용할 수 있다.
- 재료를 없애기 위한 숨은 장치를 두지 않는다. 플레이어가 사용 목적을 알 수 있어야 한다.
- 권역마다 재료의 생산 효율이 다르다. 상위 제작과 강화에는 여러 권역의 재료가 함께 필요할 수 있다.
- 모든 재료는 직접 구할 수 있다. 보통은 해당 재료를 유리하게 생산하는 플레이어와 거래하는 편이 이득이 되도록 설계한다.
- 국가나 월드 단위의 공동 프로젝트는 화폐와 재료를 소비할 수 있다. 보상으로 작은 경험치·생산 보너스, 시설 변화, 조사 기능, 명예 표시 등을 사용할 수 있다.
- 직접 지정 거래는 두지 않는다. 구매자는 판매자를 선택할 수 없다.
- 동일 품목은 낮은 판매가의 물량부터 가격 우선으로 자동 체결한다.
- 거래량이 적은 품목을 이용한 부계정 자산 이전에 대응하되, 정상적인 희귀 매물의 가격 형성을 막지 않는다.
- 시스템이 의심 매물을 설명 없이 임의 구매하는 방식은 사용하지 않는다.

## 경쟁과 최종 성장 이후

- 누적 성장과 전투력을 보여주는 장기 랭킹은 허용한다.
- 시즌 경쟁을 두더라도 캐릭터의 전체 성장을 초기화하는 방식을 기본으로 삼지 않는다. 시즌은 별도 목표와 기록을 제공한다.
- 시즌 보상은 칭호·외형·장식·기록처럼 다음 시즌의 전투력 격차를 크게 늘리지 않는 항목을 우선한다.
- 현재 버전의 모든 스킬과 주요 장비 성장을 끝낸 플레이어가 존재할 수 있다. 이를 막기 위해 전투력 계층을 끝없이 추가하지 않는다.
- 최종 성장 이후에는 도감·희귀 변종·장비 조합·길드·공동 프로젝트·시즌 기록·칭호·외형·새 지역·새 스킬을 장기 목표로 사용할 수 있다.

## 운영

- 플레이어 집단이 특정 지역의 생태를 의도적으로 바꾸는 것은 정상적인 플레이다.
- 버그·복제·허용하지 않은 자동화·정상 플레이로 만들 수 없는 플레이 기록·거래 규칙을 우회한 자산 이전에는 별도로 대응한다.
- 운영 도구는 전체 적응 정지, 특정 지역·개체군 동결, 이상 기록 제외, 상태 복구, 변화율 제한, 원인 기록 추적을 지원해야 한다.
