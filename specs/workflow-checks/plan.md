# 작업 기록 검사 작업 계획

## 변경 범위

공통 커밋 규칙, 조사·실험 문서 형식과 검사기를 main에서 작성한다. 이전 두 브랜치는 병합 없이 폐기했다. 새 에셋 생성·오픈소스 실행·성능 비교는 이번 변경에 포함하지 않는다.

## 작업 순서

- [x] 기존 지침·검사기와 tackroom 하네스 기준 확인.
- [x] 문서 책임·목차·메타정보·검사 수용 기준 정의.
- [x] 전체 에셋 조사·정의·실험·평가의 후속 작업 기록.
- [x] 기록·커밋 검사와 정상·실패 대응 테스트 구현.
- [x] CI 연결과 로컬 검사.
- [x] 별도 문체·의미 검토.

## 검증 결과

2026-10-01에 다음 검사를 수행했다. 자동 검사와 별도 검토를 구분하며, 생략한 검사를 통과 수에 포함하지 않는다.

- 기존 문서 검사기 테스트는 16개를 통과했다.
- 작업 기록 검사기 테스트는 12개 중 11개를 통과했고, 1개를 건너뛰었다. Windows 호스트에서 심볼릭 링크 생성 권한이 없어 링크를 통한 외부 경로 검사 사례를 실행하지 못했다. 일반 외부 경로 거부와 입력 파일 존재 검사는 통과했다.
- 문서 표기 검사는 14개 문서를 통과했다. 조사 기록 검사는 실제 계획 1개에서 위반이 없었다.
- 임시 Git 이력으로 검사 범위·제목 위반을 확인했고, 메시지 파일의 정상·위반·읽기 오류를 확인했다. 검사 성공·규칙 위반·실행 오류의 종료 코드를 구분했다.
- 별도 검토에서 문서 책임·목차·메타정보·용어·목록 순서·표의 명사구·수용 기준과 테스트의 대응을 확인했다. 전체 에셋 후속 범위와 첫 미완료 단계의 연결을 확인했다.
- 테스트 중 Windows의 임시 디렉터리 해제 지연을 확인했다. 정리 경로를 제한하고 제한된 재시도로 수정했으며, 재실행 후 잔여 테스트 디렉터리가 없음을 확인했다.

원격 CI 실행·필수 검사 설정과 Linux에서의 심볼릭 링크 테스트는 미확인이다. 실제 오픈소스 조사·에셋 생성·실험은 수행하지 않았다.
