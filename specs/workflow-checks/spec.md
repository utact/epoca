# 작업 기록 검사

## 목적과 기준

[작업 흐름](../../docs/workflow.md)의 커밋 형식과 [기술 조사 및 실험 지침](../../docs/engineering/research.md)의 문서 책임·메타정보·연결을 검사한다. 사람이 검토할 내용을 형식 검사 통과로 대신하지 않는다.

## 실행과 범위

- Python 3.12 이상과 Git을 사용하며 외부 패키지는 사용하지 않는다.
- `python scripts/check-workflow.py`는 Git이 추적하거나 무시하지 않는 새 조사·실험 Markdown 문서를 검사한다. 삭제한 파일과 무시한 캐시는 제외한다.
- 각 기록의 제목·목차·절 내용, 첫 절의 JSON 메타정보, 입력 파일의 존재와 저장소 내부 경로를 확인한다.
- `python scripts/check-workflow.py --commit-base <기준> --commit-head <대상>`은 두 Git 리비전 사이의 일반 커밋 제목을 검사한다. 병합 커밋과 범위 이전 이력은 제외한다.
- 새 브랜치의 push처럼 기준이 모두 0인 경우 대상 커밋 하나만 검사한다. pull request에서는 실제 기준·대상 사이를 검사한다.
- `python scripts/check-workflow.py --message-file <파일>`은 커밋 메시지 파일의 첫 줄을 추가로 검사한다.
- 알려지지 않은 기록 경로·버전·필드, 중복 JSON 키와 잘못된 자료형은 위반으로 처리한다. 미확인 값은 허용된 필드에서 이유와 함께 기록한다.
- 코드·실행 확인에는 고정 커밋의 근거 URL을 요구한다. 실행 확인에는 로컬 증거 경로도 요구한다. 보고서에는 같은 폴더의 계획을 입력으로 요구한다.
- 기존 게임 문서·기능 명세의 목차, 의미·문체·외부 URL의 내용과 모든 실험 산출물 형식은 이 검사의 범위 밖이다.

## 진단과 종료

코드는 [기술 방향 > 진단 코드](../../docs/engineering/strategy.md#진단-코드)를 따른다. 진단에는 경로·위치·기대 조건과 확인한 문제를 포함한다.

| 코드 | 검사 대상 | 수정 방향 |
| --- | --- | --- |
| WFL001 | 기록 경로와 문서 종류 | 문서 책임에 맞는 위치 |
| WFL002 | 제목·절 순서·빈 절 | 등록 목차와 내용 보완 |
| WFL003 | JSON 메타정보·버전·자료형 | 필수 값과 미확인 이유 보완 |
| WFL004 | 입력 경로·계획·고정 근거 연결 | 실제 증거와 연결 보완 |
| WFL005 | 커밋 제목 형식 | 유형·범위·한국어 요약 수정 |

| 종료 코드 | 의미 |
| --- | --- |
| `0` | 검사 범위의 위반 부재 |
| `1` | 기록·메시지의 규칙 위반 |
| `2` | 파일 읽기·Git 등 검사 실행 오류 |

검사 오류는 기록의 품질 실패와 구별한다. 0개 기록을 검사한 경우에도 검사 수를 출력하며 데이터 검증이 있었다고 해석하지 않는다. 자동 수정은 수행하지 않는다.

## 수용 기준과 확인 방법

| 수용 기준 | 확인 방법 |
| --- | --- |
| 다섯 기록 종류의 정상 형식 수용 | 종류별 정상 문서 검사 |
| 누락·중복·순서 변경·빈 절의 검출 | 정상 입력에서 한 조건을 바꾼 대응 검사 |
| 버전·시각·URL·해시·자료형·미확인 이유의 검사 | 메타정보 경계·오류 검사 |
| 계획·증거 파일의 연결과 경로 경계 검사 | 정상 연결·누락·외부 경로 검사 |
| 고정 코드 근거와 실행 증거의 구분 | 문서·코드·실행 수준별 대응 검사 |
| 커밋 범위와 제목 위반 검사 | 임시 Git 이력과 메시지 파일 검사 |
| 검사 오류와 위반의 종료 코드 구분 | CLI 성공·위반·실행 오류 검사 |
| 추적·새 문서의 검사와 무시 파일 제외 | 임시 Git 저장소 파일 탐색 검사 |

## 자동 실행과 한계

기존 문서 CI에 회귀 테스트·기록 검사·변경 커밋 검사를 연결한다. CI 실패와 실제 병합 차단은 다르며 원격 필수 검사 설정은 별도 확인한다. 후속 조사를 수행하기 전 이 형식을 실제 기록에 적용하고 분류의 빠진 항목을 검토한다.
