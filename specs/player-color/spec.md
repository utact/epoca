# 개인 색상 선택

상태: 초안

## 목적과 기준

가입 과정에서 자신의 색상을 뽑고, 실제 닉네임과 명찰에 적용한 모습을 확인한 뒤 확정하는 경험을 제공한다.

게임 규칙은 [게임 설계 > 닉네임과 개인 색상](../../docs/game/design.md#닉네임과-개인-색상)을 따른다. 미정인 게임 정책과 수치는 [미결정 사항 > 닉네임과 개인 색상](../../docs/game/open-questions.md#닉네임과-개인-색상)에서 관리한다.

이 문서의 화면 동작과 수용 기준은 검토 중이다. 구현과 검증은 아직 수행하지 않았다.

## 범위

- 최초 색상 추첨, 재추첨, 선택 결과 확정을 다룬다.
- 닉네임·명찰·채팅에서 선택한 색이 보이는 모습을 미리 보여준다.
- 새로고침·재접속·요청 실패·중복 요청 시 선택 상태와 남은 횟수의 처리를 다룬다.

채팅 채널·메시지 전송·신고 등 채팅 기능 전체와 색상 확정 후의 이벤트·상품은 해당 기능 명세에서 다룬다.

## 화면과 동작

1. 추첨 화면에서 현재 색상과 색상 코드, 남은 추첨 기회를 표시한다.
2. 현재 색을 닉네임·명찰·채팅 미리보기에 적용한다.
3. 재추첨에 성공하면 새 색과 남은 기회를 함께 갱신한다.
4. 확정한 색을 계정의 개인 색상으로 사용한다.

- 화면에 제시하는 후보 색은 선택 중 임시로 확보하고, 최종 소유와 구별한다.
- 현재 후보를 새 후보로 교체할 때 새 색 확보·이전 색 반환·기회 차감을 함께 처리한다. 교체에 실패하면 기존 색과 남은 기회를 유지한다.
- 사용 중인 색과 충돌해 서버가 내부적으로 다시 추첨하는 과정은 사용자 기회를 차감하지 않는다.
- 같은 요청의 재전송은 같은 결과를 반환하며, 기회를 추가로 차감하지 않는다. 별개의 재추첨 요청은 남은 횟수 안에서 순서대로 처리한다.
- 임시 보관 기간 안의 새로고침·재접속은 현재 후보와 남은 기회를 복원한다.
- 임시 보관이 만료된 후보는 소유권을 확인하지 않고 확정하지 않는다.
- 유사한 색의 닉네임도 이름을 읽어 구분할 수 있게 표시한다. 가독성을 위해 서로 비슷한 색을 추첨 대상에서 제외하지 않는다.

## 수용 기준과 확인 방법

| 수용 기준 | 확인 방법 |
| --- | --- |
| 동시 추첨·확정 시 색상 소유권의 유일성 | 동일 후보에 대한 동시 추첨·확정 테스트 |
| 재추첨 성공 시 후보 교체와 횟수 차감의 일괄 반영 | 재추첨 전후 후보·횟수 비교 테스트 |
| 재추첨 실패 시 기존 후보와 남은 횟수 유지 | 교체 단계별 실패 주입 테스트 |
| 응답 유실 후 동일 요청 재전송 시 최초 처리 결과와 차감 횟수 유지 | 처리 완료 후 응답 유실·동일 요청 재전송 테스트 |
| 여러 탭·연타 시 추첨 횟수 상한 준수 | 같은 계정의 병렬 요청 테스트 |
| 보관 기간 내 재접속 시 후보와 남은 횟수 복원 | 새로고침·재접속 테스트 |
| 만료·재방출 후 이전 선택 상태에 의한 색상 확정 차단 | 만료·확정 요청의 동시 처리 테스트 |
| 유사색·어두운 색·밝은 색에서 닉네임과 본문의 가독성 확보 | 대표 색상 조합별 닉네임·본문 읽기 테스트 |

횟수와 보관 시간은 결정된 정책을 사용하며, 그 전에 실시하는 실험은 임시 값을 가정으로 명시한다.

## 기능별 미결정 사항

- 임시 보관 만료 시간과 보관 연장 조건
- 임시 보관 만료 후 재진입 시 안내와 후보 재발급·기회 처리
- 이전 추첨 결과를 다시 선택할 수 있는지 여부
- 색상 코드 표기와 추첨 대상 색상 범위
- 더 이상 확보할 수 있는 색이 없을 때의 안내와 가입 처리
- 읽기 쉬운 닉네임과 개인 색상을 함께 표현하는 구체적인 화면 방식
